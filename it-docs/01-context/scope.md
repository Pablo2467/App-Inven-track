# 01 — Scope

## In scope

| **Capability** | **Note** |
| ------------------------- | ------------------------------------------------------------- |
| Product management | Register, update, categorize, and manage products |
| Stock entry management | Register quantities entering the inventory and their corresponding entry information |
| Stock exit management | Register quantities leaving the inventory |
| FIFO management | Apply the First In, First Out method when products leave the inventory |
| Inventory consultation | View current stock and product availability |
| Inventory movement tracking | Keep a record of stock entries and exits |
| User management | Allow registered users to access and operate the inventory system |

## Out of scope

| **Capability** | **Why it is excluded** |
| ------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| Online sales | Iven-Track manages inventory but does not provide an online store or e-commerce functionality |
| Customer self-service | Customers do not directly access the inventory management system |
| Supplier management | The system does not manage supplier relationships, contracts, or supplier payments |
| Accounting and financial management | The system does not calculate taxes, accounting records, or financial statements |
| Payment processing | The system does not process or manage customer payments |
| Multi-company inventory | The system is designed to manage the inventory of a single organization |
| Warehouse automation | The system does not control physical warehouse equipment or automated storage systems |
| Multi-warehouse management | The initial version does not manage independent inventories across multiple warehouses |

## Revisiting scope

An item moves from "Out" to "In" only when the product vision and corresponding requirements are updated and approved. Scope changes must be documented before they are incorporated into the system.
